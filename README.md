# Scale Flow — Updated Website

The official, modern web presence and interactive product showcase for Scale Flow.

## Tech Stack
- **Framework**: TanStack Start (React 19)
- **Styling**: Tailwind CSS
- **Animations**: GSAP
- **Icons**: Lucide React
- **Build Tool**: Vite

## Getting Started

### Prerequisites
- Node.js 22 LTS or newer
- npm or Bun

### Installation & Run

```sh
npm install
npm run dev
```

Open [http://localhost:8080](http://localhost:8080) to view the website.

### Build & Test

```sh
npm run test
npm run build
```
